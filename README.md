## MCP Servers (Official)
- **[Filesystem](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem)** - Secure local file access for agents.
- **[GitHub](https://github.com/modelcontextprotocol/servers/tree/main/src/github)** - Read repos, manage issues, and PRs.
- **[Slack](https://github.com/modelcontextprotocol/servers/tree/main/src/slack)** - Channel management and messaging.
- **[Postgres](https://github.com/modelcontextprotocol/servers/tree/main/src/postgres)** - Read-only database access.

## MCP Servers (Community)
- **[Context Bridge](https://github.com/jusspound-netizen/context-bridge)** - One MCP endpoint for Jira, Sentry, and GitHub Actions.
- **[Aave Risk Monitor](https://github.com/graphprotocol/graph-aave-mcp)** - Real-time Aave liquidation risk data across 5 chains.
- **[Playwright MCP](https://github.com/executeautomation/mcp-playwright)** - Browser automation and web scraping.

## Agent Frameworks
- **[LangGraph](https://github.com/langchain-ai/langgraph)** - Build stateful, multi-actor applications with LLMs.
- **[CrewAI](https://github.com/joaomdmoura/crewAI)** - Framework for orchestrating role-playing, autonomous AI agents.
- **[AutoGen](https://github.com/microsoft/autogen)** - Microsoft's framework for multi-agent conversation.
- **[OpenAI Agents SDK](https://github.com/openai/openai-agents-python)** - Lightweight framework for multi-agent workflows.

## Local LLMs for Agents
- **[Nemotron 3.5](https://huggingface.co/nvidia)** - NVIDIA's model built for fast local conversations and tool use.
- **[Qwen3-4B Abliterated](https://ollama.com/richardyoung/qwen3-4b-instruct-2507-abliterated)** - Uncensored, fast, and natively supports tool calling.
- **[Llama 3.1](https://ollama.com/library/llama3.1)** - The standard 8B model for agentic workflows.
